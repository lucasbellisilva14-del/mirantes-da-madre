# Mirantes da Madre

Site estático do Mirantes da Madre (antigo Recanto Amadeus), Guarda do Embaú, Palhoça/SC.

- `index.html` — site principal
- `assets/` — fotos otimizadas
- Formulário via Formspree, contato principal via WhatsApp
- Deploy: Vercel (sem build, raiz do repositório)

## Deploy

1. Suba esta pasta como repositório no GitHub.
2. Em vercel.com, **Add New → Project**, importe o repositório.
3. Framework Preset: **Other**. Build Command e Output Directory ficam vazios.
4. Deploy. Cada push na branch principal publica automaticamente.
